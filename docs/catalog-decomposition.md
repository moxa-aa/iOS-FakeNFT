**Имя:** Сардор Рахимов  
**Когорта:** 38  
**Команда:** 2

**Архитектура:** MVVM  
**Фреймворк:** UIKit  
**Сеть:** существующий `NetworkClient`, URLSession  
**Многопоточность:** GCD, `DispatchQueue`, `DispatchGroup`  
**Общая оценка:** **~29 ч 40 мин**

## Зависимости от других эпиков

- Для работы избранного используется общий `ProfileService`, реализуемый в эпике «Профиль».
- Для работы корзины используется общий `OrderService`, реализуемый в эпике «Корзина».
- До начала интеграции необходимо согласовать протоколы этих сервисов и модели запросов.
- Экран деталей NFT уже присутствует в стартовом проекте и открывается через `NftDetailAssembly`.

# Критерии готовности

## Экран каталога

- [x] Отображается список коллекций с обложкой, названием и количеством NFT.
- [x] Во время загрузки отображается `UIActivityIndicatorView`.
- [x] При ошибке отображается сообщение с возможностью повторить загрузку.
- [x] Работает сортировка по названию и количеству NFT.
- [x] Сортировка выполняется локально, без повторного сетевого запроса.
- [x] Выбранный вариант сохраняется в `UserDefaults`.
- [x] По умолчанию используется сортировка по количеству NFT.
- [x] Нажатие на коллекцию открывает её экран.

## Экран коллекции

- [ ] Отображаются обложка, название, описание и автор коллекции.
- [ ] Сайт автора открывается внутри приложения через `WKWebView`.
- [ ] Во время загрузки отображается индикатор, а при ошибке можно повторить запрос.
- [ ] NFT загружаются параллельно через `DispatchGroup`.
- [ ] NFT отображаются в сетке из трёх колонок.
- [ ] Каждая ячейка содержит изображение, рейтинг, название, цену, сердце и кнопку корзины.
- [ ] Состояния избранного и корзины соответствуют данным сервера.
- [ ] После неуспешного изменения избранного или корзины ячейка возвращается к предыдущему состоянию.
- [ ] Кнопка корзины показывает крестик, когда NFT уже находится в заказе.
- [ ] Нажатие на NFT открывает существующий экран деталей NFT.

## Архитектура и многопоточность

- [x] `ViewController` не выполняет сетевые запросы и сортировку.
- [x] `ViewModel` не содержит UIKit-кода.
- [x] Сетевые сервисы скрыты за протоколами.
- [x] Зависимости передаются через `Assembly`.
- [x] Для параллельной загрузки используется `DispatchGroup`.
- [x] Нет `async/await`, `Task` или `actor`.
- [x] Общие изменяемые данные защищены от `race condition`.
- [x] Все изменения UI выполняются в главном потоке.
